# Лабораторная работа №2

**Параллельная сортировка массива целых чисел с использованием алгоритма TimSort**

Реализовать последовательную и параллельную версии алгоритма сортировки TimSort на языке C.

Параллельная реализация использует библиотеку POSIX Threads (`pthread`) для распределения вычислений между несколькими потоками.

Массив целых чисел разбивается на несколько частей, каждая из которых сортируется отдельным потоком. После завершения сортировки отдельных частей выполняется их слияние в единый отсортированный массив.

Программа поддерживает два режима работы:

- **Последовательный** — сортировка всего массива одним потоком.
- **Параллельный** — сортировка частей массива несколькими потоками с последующим слиянием результатов.

Для оценки производительности проводятся измерения времени выполнения при различном количестве потоков. По результатам измерений рассчитываются ускорение и эффективность параллельной реализации.

---

**Компиляция и запуск:**

```bash
gcc lab2.c timsort.c -o lab2.o -pthread
./lab2.o data.txt
```
