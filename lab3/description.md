# Лабораторная работа №3

**Операционные системы**

Родительский процесс создает дочерний процесс. Взаимодействие между процессами осуществляется с помощью разделяемой памяти (POSIX Shared Memory) и именованных семафоров (POSIX Semaphores).

Родительский процесс создает область разделяемой памяти и два семафора для синхронизации работы процессов, после чего запускает дочерний процесс.

Родительский процесс передает дочернему процессу команды через разделяемую память. Для синхронизации доступа к данным используются два именованных семафора:

- `sem_parent` — сигнализирует о том, что родительский процесс записал новую команду;
- `sem_child` — сигнализирует о том, что дочерний процесс завершил обработку команды.

Дочерний процесс получает команды, обрабатывает переданные данные и при необходимости отправляет ответ родительскому процессу через разделяемую память.

**Вариант задания**

Пользователь вводит имя выходного файла, а затем последовательности целых чисел. Дочерний процесс получает последовательности чисел от родительского процесса, вычисляет их сумму и записывает результат в указанный файл.

Ввод пустой строки завершает передачу данных и приводит к завершению дочернего процесса.

---

**Компиляция и запуск:**

```bash
gcc parent.c -o parent.o
gcc child.c -o child.o
./parent.o
```
